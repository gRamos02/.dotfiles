# .dotfiles

Personal config files. Each directory mirrors the tool's config location:

| Directory          | Deployed to                              |
|--------------------|------------------------------------------|
| `alacritty/`       | `~/.config/alacritty/`                   |
| `bash/`            | `~/.bashrc`, `~/.bash_profile`           |
| `ghostty/`         | `~/.config/ghostty/`                     |
| `git/`             | `~/.gitconfig`                           |
| `i3/`              | `~/.i3/` (legacy, not on current machine)|
| `nvim/`            | `~/.config/nvim/` (LazyVim)              |
| `starship/`        | `~/.config/starship.toml`                |
| `sway/`            | `~/.config/sway/`                        |
| `tmux/`            | `~/.tmux.conf`                           |
| `tmux-sessionizer/`| `~/.config/tmux-sessionizer/`            |
| `yazi/`            | `~/.config/yazi/`                        |
